# Slack Channel Digests

Weekly or ad-hoc summaries of key Slack channels, generated via Slack AI.

## Channels tracked
- `#ai-chat` — internal AI discussion
- `#ai-news` — AI news and links

## How to add a digest
1. Open the channel in Slack
2. Ask Slack AI: "Summarize the highlights from this channel over the last week"
3. Paste the result into a new file: `YYYY-MM-DD-channel-name.md`

## File naming
`YYYY-MM-DD-ai-chat.md`, `YYYY-MM-DD-ai-news.md`, or `YYYY-MM-DD-ai-channels.md` for a combined digest.
