# Atlas Access Process

Atlas (`atlas.oreilly.com`) is O'Reilly's internal publishing/authoring system used by editorial and content staff.

## How to Grant Access (Partial Self-Service)

1. **User self-registers** at `https://atlas.oreilly.com/users/sign_up`
   - In the "Registration Code" field, enter: `OREILLYSTAFF`
   - (Note: `OREILLYUK` code exists but has a shorter expiration — avoid for staff)

2. **Nick Adams adds them to the appropriate group** (Tools/Engineering side)
   - This is the manual step that IT cannot do — Nick Adams (`nadams`) handles group assignment on the Atlas backend

## Ticket Routing

- These tickets land in **HD** or **SOL** but belong in **HD**
- **Elton Lee** (`elee`) owns the HD-side workflow — walks user through self-signup and coordinates with Nick Adams
- **Michael Seneschal** (`mseneschal`) can also handle if Elton is unavailable — he has the Atlas Team contact
- **IT does not manage group permissions directly** — that's Nick Adams / Tools team

## Account Expiration Note

Accounts registered under `OREILLYUK` have a shorter expiration. If a user's account expires, the fix is to add them to the `OREILLYSTAFF` code (50-year expiration). This is handled by the Atlas Team. Aaron Sumner was assigned to document this.
